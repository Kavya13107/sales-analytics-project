# Sales Analytics Dashboard Project

## Project Overview
This project focuses on sales data analysis using Excel, MySQL, and Power BI to generate business insights and interactive dashboards.

## Tools Used
- Microsoft Excel
- MySQL
- Power BI

## Project Workflow
1. Cleaned raw dataset in Excel
2. Imported dataset into MySQL
3. Performed SQL queries for analysis
4. Built Power BI dashboard
5. Generated final business insights report

## Key Insights
- Identified top-performing customers
- Analyzed sales and profit trends
- Compared category-wise performance
- Created interactive dashboard visualizations
